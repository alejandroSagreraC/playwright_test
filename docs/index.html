Core Features

  • Scalable E2E tests with Playwright + TypeScript.
  • Clear BDD test narratives with .feature files and step definitions.
  • POM-driven architecture for maintainable UI interactions.
  • Environment-based execution strategy for qa, stg, and prod.

Project Layout

  • features/ for Gherkin scenarios.
  • steps/ for BDD implementation and fixtures.
  • models/ for page objects.
  • playwright.config.ts for runtime setup.

Quick Start

  1. Install dependencies and browser binaries.
  2. Create your environment file from the template.
  3. Generate tests and execute the suite.
npm install
npx playwright install
copy .env.example .env.qa
npm run bddgen
npm run test:qa

Environment Sample
